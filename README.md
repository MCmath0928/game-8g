# 易 · 六十四卦

一个纯静态、零依赖的中文算卦网页：三枚铜钱摇六次，得本卦与变卦，查看卦辞、爻辞、译文与解析；另附六十四卦全库、六十甲子纳音（四柱）查询。

**在线体验**：部署后访问你的 GitHub Pages 地址即可（见下文「部署」）。

---

## 功能

| 页面 | 说明 |
| --- | --- |
| **摇卦** `#/divination` | 金钱卦（纳甲摇卦）正统玩法：摇 6 次、自下而上成卦，自动排出本卦、动爻与变卦；展示卦辞、六爻爻辞（动爻高亮）、断卦提示；支持一键六爻、复制全文、分享链接、本地历史记录 |
| **六十四卦** `#/library` | 64 卦全库：按卦名/拼音/序号/卦辞检索，按上卦、下卦筛选；点开看完整卦辞、译文、解析与六爻 |
| **纳音** `#/nayin` | 输入出生日期（可含时辰）→ 排年、月、日、时四柱及各自纳音 → 查看「三十纳音格局」的性格与事业解析；另含六十甲子检索与三十格局浏览 |
| **基础** `#/basics` | 阴阳爻、八卦表、画卦顺序、金钱卦规则、如何读一卦 |

细节：

- 本卦/变卦并排对照，动爻以朱砂色高亮并标 ○ / ×。
- 断卦按传统通行规则提示（无动爻看卦辞、一爻动看动爻爻辞、多爻动合看本卦与变卦……）。
- 结果可一键复制为纯文本，也可生成可分享的短链接（如 `#/divination?r=678978`，6 位数字依次代表六爻的 6/7/8/9）。
- 起卦历史保存在浏览器本地（localStorage），不上传任何数据。
- 全站无第三方请求、无字体 CDN、无统计脚本，可离线使用。

## 技术特点

- **纯静态**：只有 `index.html` + `css/` + `js/` + `favicon.svg`，没有构建步骤、没有 npm 依赖、没有框架。直接推到 GitHub Pages 就能跑。
- **经典脚本**：不使用 ES module，因此双击 `index.html`（`file://` 协议）也能正常使用。
- **数据内置**：`js/data/hexagrams.js`（六十四卦卦辞、爻辞、译文、解析）与 `js/data/nayin.js`（六十甲子纳音、三十格局）由 `doc/八卦.docx` 解析生成，运行时无需联网。
- **四柱算法**：太阳视黄经采用 Meeus 低精度公式 + 牛顿迭代求节气时刻，误差约数分钟；年柱以立春为界、月柱以节为界、日柱 23:00 换日（23:00–24:00 为晚子时，日柱进次日）。出生时刻若极接近节气交界会给出提示。仅作文化参考。

## 本地预览

在仓库根目录起任意静态服务器即可（不要直接用 `file://` 以外的方式跨域加载）：

```bash
# 任选其一
python -m http.server 8787
npx serve .
```

然后打开 <http://127.0.0.1:8787/index.html>。

## 部署到 GitHub Pages

### 方式一：GitHub Actions（推荐）

仓库里已带好 `.github/workflows/deploy.yml`（将整个网站目录作为 Pages 产物发布）。

1. 新建仓库，把**本项目根目录下的全部文件**（`index.html`、`css/`、`js/`、`favicon.svg`、`.nojekyll`、`.github/`）推到 `main` 分支。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送后 Actions 会自动构建并发布，页面地址形如 `https://<用户名>.github.io/<仓库名>/`。

> 若你把本目录放在仓库的子目录里（例如仓库根是 `bagua/` 的父目录），请把 `deploy.yml` 中的 `path: '.'` 改成 `path: './bagua'`（或把该子目录设为 Pages 的发布目录）。

### 方式二：从分支直接发布（不用 Actions）

1. 把全部文件推到 `main` 分支。
2. **Settings → Pages → Source** 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
3. 一两分钟后即可访问。

`.nojekyll` 已包含在项目里，用于跳过 Jekyll 处理（避免以 `_` 开头的文件被忽略）。

### 自定义域名

在仓库根目录添加 `CNAME` 文件，内容为你的域名；再到 DNS 处按 GitHub 文档配置记录。站内全部使用相对路径，更换域名/子路径无需改代码。
